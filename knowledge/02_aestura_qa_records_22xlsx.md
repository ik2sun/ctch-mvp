1. **질문 설계**: 대상 페이지의 구조화 데이터/본문에서 비브랜드 질문 추출. 범용형 + 검증형(페이지 고유 수치) 쌍. 여정 구간(정보 탐색·비교·검증·구매 직전) 분산 확인.
2. **엔진 4종 세션 초기화 질의** → 언급 여부·순위·감성·인용 URL 전수 기록.
3. **집계**: 언급 점유율 / 1순위 / 자사 도메인 인용 비중 / 상품(페이지) 간 격차 / 경쟁사 동시 호명.
4. **원문 대조**: 브랜드명 매칭 누락, 환각 제품명, 인용 경로(직접 vs 외부 경유) 확인.
5. **기술 진단**: 크롤러 UA 접근, SSR, JSON-LD 필드, title/h1/h2, hreflang, canonical, llms.txt, 가격·리뷰 정합성, 식별자.
6. **재해석**: 측정 영역이 사이트 자산과 맞는가? 브랜드/커머스 사이트 역할 분리, 지식 자산 텍스트화.
7. **한계 명시**: 단일 회차·표본·측정 범위·도구 한계.
