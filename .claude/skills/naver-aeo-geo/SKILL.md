# 네이버 AEO · GEO

네이버는 글로벌 AI 엔진과 색인·인용 논리가 다르다. **네이버 자체 색인을 우선**하고, 블로그·카페·지식iN 등 자사 UGC 생태계가 인용의 대부분을 차지한다. 외부 사이트는 서치어드바이저 등록과 Yeti 허용 없이는 후보군에 들기 어렵다.

## 1. 두 표면

| 항목 | AI 브리핑 | AI 탭 |
|---|---|---|
| 위치 | 통합검색 최상단 요약 카드 (Google AI Overviews에 대응) | 별도 대화형 탭 (Google AI Mode에 대응) |
| 출시 | 2025년 3월 정식 | 2026년 6월 26일 전체 사용자 정식, 두 달 만에 누적 400만 사용자 |
| 노출 범위 | 2026년 7월 기준 전체 검색의 약 27%, 2026년 말 약 40%까지 확대 계획. 2026년 7월 21일 광고 도입 | 대화 이어가기, 예약·구매 액션 통합 |
| 답변 생성 | 여러 문서를 종합해 요약, 출처 카드 표시 | 답변 계획(질문 분해) → 정보 탐색(네이버 내부 + 외부) → 답변 생성 → 정리(출처 카드·액션). 응답 수 초~10초 |
| 인용 단위 | **단락**. 페이지 전체가 아니라 질의 의도에 맞는 원문 단락을 모아 인용 | 동일 |
| 출처 구성 | 최대 약 70%가 UGC(블로그·카페·지식iN)라는 관찰. 순위 상위 10위 밖 콘텐츠가 인용의 약 49%라는 관찰(순위와 인용은 별개 흐름) | 네이버 생태계 + 외부 웹 |

## 2. 인용 기준 3축

1. **C-Rank (출처 신뢰도)**: 특정 주제를 얼마나 전문적이고 꾸준히 발행했는지를 채널(블로그·사이트) 단위로 점수화. 주제를 섞은 채널은 불리. 한 분야를 누적한 채널이 우위.
2. **D.I.A.+ (문서 의도 부합도)**: 문서 단위로 질의 의도와의 부합, 정보성·경험성·구체성을 평가. 경험 기반 구체 정보와 수치가 유리.
3. **스마트블록·인기주제 대응**: 통합검색이 질의를 세부 주제 블록으로 쪼개 노출한다. 세부 주제에 딱 맞는 문서가 블록에 들고, 그 문서가 AI 브리핑의 후보가 된다.

추가 축: **AI 크롤러 접근** — Yeti 허용, robots.txt, llms.txt 제공 여부.

## 3. 외부 사이트(자사 도메인) 체크리스트

- [ ] **서치어드바이저**(searchadvisor.naver.com) 사이트 등록·소유 확인, 사이트맵·RSS 제출
- [ ] robots.txt에서 `User-agent: Yeti` 허용 (네이버 검색로봇, 2007년부터 사용, 국제 표준 준수)
- [ ] 서치어드바이저 "웹페이지 수집 요청"으로 핵심 URL 수집 요청, "수집 현황"에서 오류 확인
- [ ] 서치어드바이저 사이트 간단 체크: robots, 사이트맵, 메타(title·description), Open Graph, canonical, 모바일
- [ ] `<title>`에 페이지 고유 제목(브랜드명만 반복 금지), `<h1>` 1개, 질문형 `<h2>` 2~7개
- [ ] 첫 문단에 정의문 패턴("X는 Y를 의미합니다", "X는 Y입니다") 배치 → 결론 먼저, 근거 다음 순서의 한국어 문단
- [ ] 질문형 소제목 아래 2~3문장의 직접 답변 단락 (질의와 소제목이 매칭될 때 그 아래 단락이 추출됨)
- [ ] 표·리스트·단계별 설명, 각 섹션이 독립적으로 완결
- [ ] FAQ·HowTo 스키마(JSON-LD). FAQ 스키마 적용 시 인용 확률 상승 보고(약 3.2배, 출처 원포인트)
- [ ] 데이터·주장에 출처 명시, 갱신 날짜 표기, 정보 변경 시 본문 업데이트
- [ ] 영상 중심 페이지에는 동일 내용의 **텍스트 버전**을 함께 둔다 (AI는 영상을 읽지 않음)
- [ ] `content-language`·`lang="ko"` 정합 (콘텐츠가 한국어인데 en-US 헤더인 사례 있음)

## 4. 네이버 생태계 대응 (외부 채널 전략)

네이버 AI 브리핑은 네이버 색인을 우선하므로, 자사 도메인만으로는 한계가 있다. Perplexity에서 블로그 경유 인용이 1순위를 만든 것과 같은 논리로, **네이버 안에 자사 문장이 옮겨 적힌 문서**가 필요하다.

| 채널 | 역할 | 실무 포인트 |
|---|---|---|
| 네이버 블로그(공식/인플루언서) | C-Rank 누적 채널, 인용의 최대 원천 | 한 주제 카테고리 일관 발행, 상세페이지 고유 문구·수치를 그대로 쓰게 유도 |
| 인플루언서 검색 | 주제별 전문 창작자 노출 | 키워드 챌린지 참여 창작자와 협업 |
| 카페 | 경험·Q&A형 인용 | 사용 후기·비교 질문 응답 |
| 지식iN | 질문형 질의의 직접 답변 원천 | 전문가 답변(eXpert) 계정 운영 |
| 플레이스 | 지역·방문형 질의(병원·매장) | 정보 정합, 리뷰, 예약 연동 (AI 탭 액션과 연결) |
| 스마트스토어·브랜드스토어 | 가격·재고·리뷰 정형 데이터 | 상품 정보 정합, 리뷰 수 |
| 뉴스·프레스 | 신뢰 신호 | 수치·연구 결과 보도자료 |

## 5. 측정 방법

- 비브랜드 질의를 네이버 통합검색에 입력해 AI 브리핑 트리거 여부, 출처 카드 도메인, 자사 등장 여부·순위를 기록한다. AI 탭에서 동일 질의로 재측정한다.
- 출처 카드 도메인을 유형(블로그·카페·지식iN·뉴스·자사·커머스·외부 웹)으로 분류해 비중을 낸다.
- 같은 질의에서 스마트블록 구성(어떤 세부 주제 블록이 뜨는지)을 기록한다. 블록 주제가 곧 콘텐츠 세분화 기준이다.
- 글로벌 엔진과 동일 질문 세트로 측정하되, 결과 표에서 네이버 열을 분리한다. 색인 원천이 다르므로 합산 점유율에 섞지 않는다.
- 단일 회차로 판정하지 않는다. AI 브리핑 노출 비율 자체가 확대 중이므로 트리거 여부도 시계열로 본다.

## 6. 글로벌 엔진과의 차이 요약

| 항목 | Google AIO / ChatGPT / Perplexity | 네이버 AI 브리핑 |
|---|---|---|
| 색인 | 웹 전체(각사 인덱스) | 네이버 색인 우선 |
| 주 인용 출처 | Reddit·Wikipedia·리뷰 사이트·블로그·유튜브 | 네이버 블로그·카페·지식iN·뉴스 |
| 채널 신뢰 | 도메인 권위·E-E-A-T | C-Rank(채널 주제 일관성) |
| 크롤러 | OAI-SearchBot·Googlebot·PerplexityBot 등 | Yeti |
| 등록 도구 | GSC·Bing Webmaster | 서치어드바이저 |
| 행동 연결 | 외부 링크 | 예약·구매 액션 통합(AI 탭) |
